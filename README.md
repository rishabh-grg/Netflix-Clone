# Netflix India Homepage Clone 🎬

A front-end clone of the Netflix India homepage built using **HTML and CSS**. This project recreates the look and feel of Netflix's landing page while practising web development fundamentals.

## 🌐 Project Overview

The webpage includes a Netflix-inspired hero section, trending movie posters, reasons to join, frequently asked questions, and a footer.

## ✨ Features

- **Hero Section:** Background image, Netflix logo, heading, and membership information.
- **Navigation Bar:** Language selection dropdown and Sign In button.
- **Email Form:** Email input field and Get Started button.
- **Trending Movies:** Horizontally scrollable movie posters with hover effects.
- **Reasons to Join:** Grid layout with icons and descriptions.
- **FAQ Section:** Expandable questions using HTML `<details>` and `<summary>` elements.
- **Footer:** Useful links, language selector, and additional information.
- **Hover Effects:** Interactive visual effects for buttons and movie posters.
- **Responsive Styling:** CSS media queries for smaller screens.

## 🛠️ Technologies Used

- **HTML5** — Page structure and content.
- **CSS3** — Styling, layouts, gradients, hover effects, and responsiveness.

## ⚠️ Limitations

This is a front-end practice project and is **not an official Netflix website**.

- Sign In and footer links are placeholders.
- The email form does not create an account or process subscriptions.
- The language selector is a visual interface and does not translate the page.
- Movie posters are displayed for demonstration purposes.

## 🎯 Purpose

The goal of this project is to practise HTML and CSS by recreating a familiar website layout and improving front-end development skills.
